# MiDoc

MiDoc es un marketplace de salud que conecta pacientes con doctores, consultorios, clínicas y hospitales. Los pacientes usan la plataforma gratis para buscar profesionales de salud, agendar citas y llevar su expediente médico digital, que les pertenece y controlan (deciden con quién compartirlo). Los doctores y consultorios pagan una suscripción mensual de $20 USD para dar seguimiento a sus pacientes, gestionar citas, recetas, inventario y promociones.
