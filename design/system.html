Componentes

Reglas, no sugerencias. Los estados existen todos: reposo, hover, foco, activo, deshabilitado.

Botones

Campos

La etiqueta va siempre visible. El error se asocia con aria-describedby y se anuncia con role="alert".

Lo que este sistema corrige del CSS actual

  • 28 hex sueltos → 20 tokens con uso declarado.
  • Dos colores de foco distintos → uno solo, 11.87:1.
  • Bordes de campo a 1.29:1 → --color-border-strong a 3.42:1, que es el mínimo para componentes.
  • Deshabilitado con opacity → tokens propios que no rompen el contraste.
  • 5 !important y 6 bloques duplicados → una sola fuente de verdad.
